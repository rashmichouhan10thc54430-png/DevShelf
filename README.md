DevShelf 📚

A curated Developer Resource Hub that helps learners discover useful resources for Web Development, AI/ML, Android Development, and UI/UX.

✨ Features

- 🔎 Search resources by name or description
- 🗂️ Filter resources by category
- 👍 Upvote useful resources
- ➕ Add new resources through a contribution form
- 🌙 Dark mode
- 📱 Responsive design for different screen sizes

🛠️ Built With

- HTML
- CSS
- JavaScript
- LocalStorage for saving user preferences and locally added resources

🚀 How to Run

1. Clone or download this repository.
2. Open "index.html" in your browser, or use VS Code with Live Server.
3. Explore and contribute developer resources.

💡 Purpose

DevShelf makes it easier for students and developers to find helpful learning resources in one place.

👩‍💻 Project

Created as a developer resource hub project for the GDGOC AITR recruitment task.
